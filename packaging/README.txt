슈크인 홈 PC 프로텍터 (SCHomeGuard) v1.2  —  슈퍼크리에이티브 보안관제(SOC)
==========================================================================
※ 슈크인(슈퍼크리에이티브 구성원)의 "개인 집 PC 전용"입니다. 회사 PC에는 설치하지 마세요.
  회사 PC는 보안관제가 별도의 관리 도구로 보호합니다.

집 PC에서 문제가 생겼을 때, 출처가 확인되지 않은 정보나 도구(검색으로 찾은 '정리 프로그램',
무료 다운로드 사이트의 설치파일 등)로 대응하다가 오히려 위험해지는 일을 막기 위해 만들었습니다.
보안관제가 확인한 위협 정보와 검증된 방법만 씁니다.

■ 실행 방법
  1. 받은 zip 파일을 오른쪽 클릭 → [속성] → 아래쪽 [차단 해제] 체크 → [확인]
  2. 압축을 풀고 SCHomeGuard.exe 더블클릭 → 관리자 권한 창에서 [예]
  · "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행] (코드 서명 전이라 나오는 안내입니다)
  · exe 실행이 막히면 Run_PowerShell.cmd 를 더블클릭해도 같은 화면이 뜹니다.

■ 사용 순서
  1. 위쪽에 빨간 경고 띠가 보이면 [자세히 보기] — 백신(Windows Defender)이 제대로 켜져 있지 않은 PC입니다.
  2. 왼쪽 [모두 켜기] — 보호 4가지를 켭니다(스위치로 하나씩 켜고 끌 수도 있음).
  3. 오른쪽 [검사 시작] — 1~2분 걸립니다.
  4. 발견된 항목이 있으면 [선택 항목 제거]
     · '위험'은 자동으로 선택됩니다. '의심'은 직접 확인 후 선택하세요.
     · 제거 전에 시스템 복원 지점을 만들고, 지우는 레지스트리·폴더는 백업합니다.
     · '랜섬웨어 흔적'은 복구에 필요할 수 있어 지우지 않습니다 — 인터넷을 끊고 보안관제에 알려 주세요.
  5. [결과 저장] — 바탕화면에 결과 파일이 생깁니다. 문제가 있으면 이 파일을 보안관제로 보내 주세요.

■ 무엇을 막나요 (화면의 "무엇을 막나요?"에서 목록과 출처를 볼 수 있습니다)
  · 프록시웨어 검사·제거 — PC 인터넷 회선을 남에게 빌려주는 프로그램 15종과 회선 공유 SDK
  · 위험 사이트 차단 — 끼워팔기 다운로드 사이트, 보안관제가 확인한 악성 서버(브라우저 5종)
  · 방탄호스팅 통신 차단 — 방탄호스팅·Spamhaus DROP 대역(Windows 방화벽), 차단 기록과 차단 프로그램 표시
  · 원치 않는 앱(PUA) 차단 — Windows Defender·Edge
  · 랜섬웨어 보호 — 제어된 폴더 액세스 + 숨긴 미끼 파일 감시(건드리면 즉시 경고)
  · PC 보안 상태 — Defender 꺼짐·서명 오래됨 경고, 예외 폴더 정밀 검사(보고 전용, 파일은 건드리지 않음)

■ 자동 업데이트
  매일 GitHub(supercre/schomeguard, supercre/schomeguard-db)에서 새 버전과 위협 목록을 확인하고,
  보안관제의 서명이 맞을 때만 적용합니다. 화면 아래 [업데이트 확인]으로 바로 확인할 수도 있습니다.

■ 참고
  · 기록·백업 위치: C:\ProgramData\SCHomeGuard
  · 원래대로 돌리기: 각 카드의 스위치를 끄면 바꾼 설정이 원래대로 돌아갑니다.
  · 브라우저에 "조직에서 관리" 표시가 생기는 것은 위험 사이트 차단 정책 때문이며 정상입니다.
  · 명령줄: SCHomeGuard.exe -Cli -Action Scan | Clean | Protect | Unprotect | Status | Detail | Update
